# FridgePaper

냉장고 속 재료를 활용해 레시피를 찾고, 부족한 재료를 장보기로 연결하는 스마트 식생활 플랫폼입니다.

음식물 낭비를 줄이고 사용자의 메뉴 고민을 덜어주는 서비스를 목표로 기획·제작한 팀 프로젝트입니다.

## 나의 담당 작업

- 서브페이지 1의 디자인과 퍼블리싱
- 브랜드 가치, 브랜드 소개, 서비스 소개 영역 구현
- 재료 입력부터 레시피 추천까지 이어지는 AI 추천 과정 구성
- 메인페이지의 `오늘의 추천 메뉴` 영역 구현
- PC, 태블릿, 모바일 화면에 맞춘 반응형 스타일 적용

## 서비스 흐름

> 냉장고 재료 선택 → 상황과 취향 선택 → 레시피 추천 → 부족한 재료 확인 → 장보기

## 주요 화면

- 메인: 냉장고 재료 선택, 추천 테마, 공지와 이벤트
- 서비스 소개: 브랜드 가치와 AI 추천 과정 안내
- 레시피: 재료·상황·기분·음식 종류에 따른 레시피 추천
- 장보기: 부족한 재료 확인과 외부 쇼핑몰 연결
- 고객지원: 공지사항, 이벤트, FAQ

## 주요 구현

- 재료 추가·선택·삭제 기능
- 상황과 음식 카테고리 선택
- 추천 레시피 카드와 상세 모달
- 관심 레시피 저장 화면
- 로그인 모달
- Swiper를 활용한 콘텐츠 슬라이드
- GSAP을 활용한 화면 효과
- PC, 태블릿, 모바일 반응형 레이아웃

## 사용 기술

- HTML5
- CSS3
- JavaScript
- jQuery
- Swiper
- GSAP
- 반응형 웹

## 디자인

- 메인 컬러 `#348728`을 사용해 건강하고 신선한 이미지를 표현했습니다.
- Pretendard 서체와 카드형 UI를 사용해 많은 정보를 구분했습니다.
- 공통 색상은 CSS 변수로 관리하고 화면 크기에 따라 레이아웃이 변경되도록 구성했습니다.

## 구현 범위

현재 결과물은 서비스 기획과 웹 퍼블리싱을 보여주기 위한 프런트엔드 프로토타입입니다.

- 실제 AI 분석과 추천 API는 연결되어 있지 않습니다.
- 레시피와 영양 정보는 기능 시연을 위한 예시 데이터입니다.
- 로그인과 회원 정보는 실제 서버에 저장되지 않습니다.
- 외부 쇼핑몰 연결은 구매 흐름을 보여주기 위한 예시 기능입니다.
